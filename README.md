# EG Dynasty Recap

Public weekly recap + power rankings for the EG Dynasty Sleeper dynasty
league, served via GitHub Pages from this repo's `index.html`.

This repo intentionally contains **only** the generated page — no config,
no personal data, nothing else. It's regenerated automatically every
Tuesday morning by an automation that lives in a separate, private repo.

Live at: https://mlahera.github.io/eg-dynasty-recap/ (once GitHub Pages is
enabled in this repo's Settings → Pages).
